# AuthenticatorDesk 安全模型

[English](SECURITY-MODEL.md) | [简体中文](SECURITY-MODEL.zh-CN.md)

本文说明当前源码实现的安全边界，不构成安全认证。AuthenticatorDesk 尚未接受独立安全审计。

## 资产与范围

本地保险库可能包含共享密钥、账户和签发方名称、备注、服务配置数据、计数器以及应用设置。取得共享密钥的人通常就能为对应账户生成有效的一次性验证码。因此，保险库、备份、OTP Auth URI、二维码图片、WinAuth 导出文件以及显示密钥的截图都应按凭据保护。

本应用的设计目标是：

- 不依赖服务器或云账户，在本地生成 OTP 验证码；
- 检测已加密保险库内容的篡改或损坏；
- 提供主密码或 Windows 账户级访问保护；
- 锁定保险库时，从当前应用状态中移除已解密条目和会话密钥；
- 减少剪贴板及桌面界面的暴露，但不承诺彻底消除。

本应用无法防御保险库解锁期间的恶意软件、调试器、键盘记录器、屏幕捕获、管理员或其他能够检查本进程的程序。

## 保险库保护模式

当前所有模式都使用 AES-256-GCM 加密 JSON 数据，并使用全新的 12 字节 nonce、16 字节认证标签和与版本绑定的关联数据。模式之间最重要的差别是 AES 密钥如何保护。

| 模式 | 密钥处理 | 可移植性 | 安全边界 |
| --- | --- | --- | --- |
| 便携模式（默认） | 随机 256 位密钥与密文保存在同一个保险库封装中 | 可复制到另一台 Windows 电脑 | 能检测损坏并避免明文 JSON，但保险库文件被复制或窃取时，**不提供访问保护** |
| 主密码 | 使用 16 字节随机盐和 600,000 次 PBKDF2-HMAC-SHA256 从密码派生密钥 | 知道密码即可迁移 | 安全性取决于密码强度；没有密码恢复功能 |
| Windows 账户 | 随机 256 位密钥由当前用户范围的 Windows DPAPI 保护 | 绑定同一 Windows 用户环境 | 有助于阻止其他账户或电脑解开复制的保险库；不能防御已在该 Windows 用户身份下运行的代码 |

除非明确需要无访问保护的便携性，新用户应设置高强度主密码或启用 Windows 账户保护。

## 锁定与内存

成功锁定时，AuthenticatorDesk 会先保存待处理改动、注销全局快捷键、清除通过受保护复制流程写入且尚未变化的 OTP 剪贴板内容、清零会话密钥字节数组、从当前模型中移除条目密钥及服务配置数据，并用锁定界面替换主面板。

这些措施属于纵深防御，不是安全内存保证。应用使用 .NET 托管对象和字符串，副本可能在运行时回收前继续存在。保险库解锁期间，能够检查进程内存的程序不在保护边界内。

## 剪贴板与自动输入

从主界面或全局复制快捷键复制的 OTP 验证码，可以在设定延时后清除。只有剪贴板仍包含 AuthenticatorDesk 原先写入的同一内容时才会清除，因而不会删除后来复制的新内容。

该定时器并不覆盖所有敏感对话框。通过导出对话框显示或复制的共享密钥、恢复码及完整 OTP Auth URI 都必须按明文凭据处理。其他桌面应用也可能在定时清除前读取剪贴板。自动输入和通知动作还会把验证码暴露给当前桌面目标或通知界面。

## 备份、导入与导出

- 原生 `.authdesk` 备份包含验证器条目，但不包含全部应用设置；它使用 600,000 次 PBKDF2-HMAC-SHA256 和 AES-256-GCM。
- 明文 OTP Auth URI 导出、二维码图片和未加密 WinAuth XML 都包含可恢复的共享密钥。
- 密码保护的 WinAuth XML 使用 WinAuth 的旧式兼容方案（2,000 次 PBKDF2-HMAC-SHA1 与 Blowfish）。新建加密备份应优先使用原生 `.authdesk` 格式。
- Windows 保护的 WinAuth 数据只能在兼容的 Windows 保护环境中打开；不支持 YubiKey 保护的 WinAuth 数据。
- 导入内容只作为输入数据处理，但成功导入仍会把其中的密钥带入本地保险库。请验证来源，并在迁移完成后安全删除不再需要的明文文件。

保险库保存流程使用临时文件并保留 `.bak` 副本。备份副本与主保险库具有相同的保护属性，也必须采用相同级别的保护。

## 本地数据与诊断

当前应用源码没有实现网络客户端、云同步、遥测、账户服务、更新检查或网络时间同步。TOTP 使用 Windows 系统时钟。

致命错误日志写入所选数据目录，可能包含异常详情、文件路径和诊断上下文。应用不会自动上传日志，但公开分享前应先检查内容。

数据流摘要参见 [PRIVACY.zh-CN.md](../PRIVACY.zh-CN.md)。

## 不在保护范围内的威胁

AuthenticatorDesk 本身无法防御：

- 同一 Windows 安装中的恶意软件或恶意管理员；
- 弱主密码、重复使用的密码以及离线密码猜测；
- 通过截图、剪贴板管理器、命令历史、导出文件、备份或用户选定的云同步目录泄露；
- 签发 OTP 密钥的服务本身被攻破；
- 唯一保险库副本丢失或主密码遗忘；
- 错误或被恶意修改的系统时钟；
- Windows、.NET 或所带依赖中的漏洞。

请将恢复码另行保管，维护并验证备份，锁定工作站，及时安装系统更新，并在发布前审查依赖更新。

## 审查状态

密码学设计和实现包含兼容性测试及已知向量自动化测试，但尚无独立审计。发现疑似漏洞时，请按照 [SECURITY.zh-CN.md](../SECURITY.zh-CN.md) 报告，不要在公开 Issue 中粘贴真实凭据或密钥。
